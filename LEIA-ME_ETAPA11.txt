ETAPA 11 - EXTRAÇÃO DO CARREGAMENTO DE DADOS DO FINANCEIRO

Arquivos principais desta etapa:

1. Novo arquivo:
   src/hooks/financeiro/useFinancialData.ts

2. Arquivo atualizado:
   src/app/financeiro/page.tsx

O novo hook passou a concentrar:
- carregamento inicial do financeiro;
- recarregamento dos dados;
- registros financeiros;
- transações de pagamento;
- despesas;
- pacientes;
- saldos por paciente;
- estado geral de carregamento.

Nenhuma regra de cálculo, reconciliação financeira ou consulta foi alterada.
O hook continua utilizando loadFinancialPageData(), do financeiroService.ts.

COMO APLICAR

Copie a pasta src deste pacote sobre a pasta src do projeto.

Dentro da pasta do projeto, execute:

npm run build
npm run dev

TESTES RECOMENDADOS

1. Abrir o Financeiro e confirmar que todos os dados carregam.
2. Atualizar a página no navegador.
3. Registrar um pagamento e confirmar a atualização dos indicadores.
4. Editar um pagamento e confirmar a atualização dos saldos.
5. Criar e excluir um lançamento financeiro.

COMMIT SUGERIDO

git add .
git commit -m "Extrai carregamento de dados do financeiro"

IMPORTANTE

Este pacote não envia nada ao GitHub ou ao Vercel.
As alterações permanecem apenas no projeto local até que seja executado git push.
