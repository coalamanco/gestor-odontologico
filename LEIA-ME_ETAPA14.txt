ETAPA 14 — CORREÇÃO DE DATAS LOCAIS NO FINANCEIRO

Arquivos alterados:
- src/lib/financeiro/financeiroUtils.ts
- src/hooks/financeiro/useFinancialPaymentActions.ts
- src/app/financeiro/page.tsx

O que foi corrigido:
- Datas de hoje agora são geradas no fuso local do navegador, sem depender de UTC.
- Data padrão dos modais de recebimento e edição usa a data local.
- Vencimentos das parcelas usam formatação local YYYY-MM-DD.
- Evita o risco de aparecer o dia anterior em horários próximos da meia-noite no Brasil.

Nenhuma regra financeira, consulta ou estrutura do banco foi alterada.

Depois de copiar a pasta src:
1. npm run build
2. npm run dev
3. Testar criação de lançamento parcelado e abertura dos modais.
4. git add .
5. git commit -m "Corrige datas locais do financeiro"
