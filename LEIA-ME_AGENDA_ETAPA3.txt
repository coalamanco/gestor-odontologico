REORGANIZAÇÃO DA AGENDA — ETAPA 3

Objetivo:
- Centralizar os estados e o carregamento dos dados da Agenda em um hook.

Novo arquivo:
- src/hooks/agenda/useAgendaData.ts

Arquivo atualizado:
- src/app/agenda/page.tsx

O hook concentra:
- pacientes;
- profissionais;
- agendamentos;
- bloqueios;
- registros financeiros;
- modelos de mensagens;
- configurações da clínica;
- carregamento inicial;
- recarregamento dos dados;
- estados de loading e erro.

Nenhuma regra de criação, edição, exclusão, arrastar, redimensionar, Google Agenda ou WhatsApp foi alterada.

Depois de copiar a pasta src para o projeto, execute:

npm run build
npm run dev

Teste a abertura da Agenda, Dia/Semana, agendamentos, bloqueios, arrastar, redimensionar e sincronização.

Commit sugerido:

git add .
git commit -m "Extrai hook de dados da agenda"
